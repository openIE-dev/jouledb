# jouledb examples

Runnable example programs for jouledb. Each subdirectory is an independent example with its own README explaining what it shows and how to run it.

## Install

```bash
cargo binstall jouledb
# or
cargo install jouledb
# or download from https://github.com/openIE-dev/jouledb/releases
```
