# Introduction

**JouleDB (`v0.9.0` Pre-1.0 Research Preview)** is an open-source (`Apache-2.0 OR MIT`) multi-model database, hyperdimensional semantic store, MCP Apps (`SEP-1865`) host, and experimental low-bitwidth tensor runtime written in Rust.

> **Audit Remediation (`v0.6.0`) & Engine Upgrades (`v0.7.0`–`v0.9.0`, 2026-11-26):** Following an external source-level audit in November 2026, **`v1.0.0` was retracted/yanked**, synthetic frontier AI exam routes (`frontier_exam_routes.rs`) and the unrelated `1.11M`-line `joule-web` crate were deleted, 81 unverified low-BPW `.jsyn` causal LLM checkpoints were removed from Hugging Face, and Linux release binaries were rebuilt against `GLIBC <= 2.35` (verified on Ubuntu 24.04 LTS). **`v0.9.0`** adds built-in **Claude/MCP Apps (`SEP-1865`) Studio UI (`ui://jouledb/studio.html`, `50` tools, `.mcpb` bundles)**, speeds up the **entire official `99,997,497`-row (`14.78 GB`) ClickBench `hits.parquet` suite `1.72×` (`43 / 43` queries, `0` errors, `6.20 GB` post-load RSS / `15.48 GB` kernel `VmHWM` peak, `2.82×` geomean latency & `2.43×` `reported_j` vs DuckDB `2.0.1`, `8 / 43` wins, `Q32` `7.24×` faster)**, accelerates **`pgwire` Extended Pipeline OLTP `3.01×` (`1,790 TPS` Pipelined, `3,351 TPS` Simple vs `PostgreSQL 16.16` & `SQLite 3.53.1`)**, verifies **5-node Multi-Host Cross-Machine WAN/Tailscale TCP Raft (`ReadIndex` + `SIGKILL` + `raft.wal`)** with official Clojure `elle 0.2.8` (**`{:valid? true}`**), and enforces **`deny(clippy::unwrap_used)` across `7` core crates**. All benchmark scripts, raw JSON/EDN outputs, wins, and losses are published in [`bench/`](https://github.com/openIE-dev/jouledb/tree/main/bench).

## Core Subsystems

1. **[Claude Apps, MCP Apps (`SEP-1865`) & `.mcpb` Bundles](./claude-apps.md):** Built-in interactive **JouleDB Studio** (`ui://jouledb/studio.html`, `text/html;profile=mcp-app`), `jouledb mcp --data <dir>` (`stdio`), `POST /mcp` (`50` tools), Claude Desktop `.mcpb` bundles, and Antigravity plugin.
2. **[Storage, MVCC SSI & PITR](./pitr-and-abi.md):** B-Tree storage, Write-Ahead Logging (`WAL`), Serializable Snapshot Isolation (`SSI`), index-assisted `MvccTableStorage` with `O(1)` PK/UNIQUE index checks and group-committed WAL batches, Copy-on-Write (`CoW`) branching (`joule-db-branch`), binary `TLV` + `CRC-32` envelope framing, and WAL `LSN`/timestamp recovery (`v1_stability_and_pitr.rs`).
3. **[SQL, Out-of-Core `.jcol` Columnar Engine & Multi-Host WAN TCP Raft](./sql-and-consensus.md):** SQL execution over HTTP and PostgreSQL v3 wire (`pgwire` with static `Describe` type inference), row-budgeted streaming Parquet `COPY` spilling `262,144`-row `.jcol` disk segments, vectorized `execute_segmented` (`43 / 43` Official ClickBench on all `99,997,497` rows), window functions, `CUBE`, recursive CTEs, `ALP`/`FSST` codecs, and networked TCP Raft (`raft.rs`, `raft_transport.rs`, `examples/raft_wan_node.rs`) with `propose_and_commit`, Raft §6.4 `read_linearizable` (`ReadIndex`), TLA+ specifications, and multi-host WAN Clojure `elle` (`0.2.8`) verification.
4. **[Amorphous Hyperdimensional Store](./amorphic.md):** Extracts typed semantic atoms (`JSON`, `CSV`, `XML`, `k=v`, prose, triples) into `10,240`-bit Vector Symbolic Architecture (`VSA`) bitvectors with SI unit normalization and bounded-memory streaming.
5. **[Experimental `.jsyn` Low-Rank Bitplanes](./jsyn.md):** Compresses 2D projection tensors into packed binary sign bitplanes (`LittleBit-2 + SVF`). Preserves `0.9441` cosine similarity on compact sentence encoders (`all-MiniLM-L6-v2-LittleBit` at `0.44 BPW`), while ultra-low `0.02–0.17 BPW` settings degrade autoregressive LLMs (`cos = 0.27–0.45`) and are **not** drop-in LLM replacements.
6. **[Wire Adapters & Unaudited Security Controls](./trust.md):** PostgreSQL `pgwire` (tested against `psql`, `psycopg3`, `node-pg`, `JDBC`, `SQLAlchemy`), REST compatibility adapters, and technical security primitives — **explicitly unaudited by any external SOC 2, HIPAA, PCI-DSS, CMVP, or FedRAMP assessor**.
