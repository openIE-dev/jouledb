# Introduction

**JouleDB (`v0.15.0` Pre-1.0 Research Preview)** is an open-source (`Apache-2.0 OR MIT`) multi-model database, SQL-native double-entry core-banking ledger, sub-millisecond Copy-on-Write agent sandbox, hyperdimensional semantic store, MCP Apps (`SEP-1865`) host, and experimental low-bitwidth tensor runtime written in Rust.

> **Audit Remediation (`v0.6.0`) & Engine Upgrades (`v0.7.0`–`v0.15.0`, 2026-11-27):** Following an external source-level audit in November 2026, **`v1.0.0` was retracted/yanked**, synthetic frontier AI exam routes (`frontier_exam_routes.rs`) and the unrelated `1.11M`-line `joule-web` crate were deleted, 81 unverified low-BPW `.jsyn` causal LLM checkpoints were removed from Hugging Face, and Linux release binaries were rebuilt against `GLIBC <= 2.35` (verified on Ubuntu 24.04 LTS). **`v0.15.0`** enforces **`deny(clippy::unwrap_used)` across all `41 / 41` workspace crates (`100%`, `0` bypasses)**, reaches **`104,721.1 TPS` (`0.54 mJ/tx`) `pgwire` & `102,276.0 TPS` HTTP on durable NVMe core-banking clearing batches (`1.93×` faster than `PostgreSQL 16.16`), `3,544.6 TPS` at `c=1` (`9.15×` faster), and `3,461.3 TPS` at `c=16` (`1.00×` parity/lead)**, cuts **lazy `O(1)` CoW `CREATE BRANCH` latency `63×` to `0.605 ms` (`0.432 ms` on Apple Silicon)** with native **`pgvector` HNSW SQL (`<->`/`<=>`/`<#>`)**, narrows the **entire official `99,997,497`-row (`14.78 GB`) ClickBench `hits.parquet` suite to `2.11×` geomean latency (`2.03×` `reported_j`) vs DuckDB `2.0.1` (`43 / 43` queries, `5.90 GB` post-load RSS, `7 / 43` wins)**, completes **`22 / 22` (`100%`) Official `TPC-H` queries exact across `SF = 0.1` (`1.99×` geomean, `5` wins), `SF = 1.0` (`1.59 s`, `4.15×` geomean, `204 MB` RSS, `575 MB` peak `VmHWM`), AND `SF = 10.0` (`86.6M` rows in `758 MB` post-load RSS & `4.01 GB` peak `VmHWM` [`3.88×` down], `8.17×` geomean, `Q18` `827.7 ms`)**, accelerates **`c=4..8` physical-NVMe `100`-warehouse `pgwire` OLTP `1.43×–1.90×` via pre-allocated `WalManager` extents (`5,154 TPS` at `c=16`, `invariant_verified = true`)**, ships **Claude/MCP Apps (`SEP-1865`) Studio UI (`ui://jouledb/studio.html`, `59` tools, `.mcpb` bundles)**, and verifies **5-node Multi-Host Cross-Machine WAN/Tailscale TCP Raft (`ReadIndex` + `SIGKILL` + `raft.wal`)** with official Clojure `elle 0.2.8` (**`{:valid? true}`**). All benchmark scripts, raw JSON/EDN outputs, wins, and losses are published in [`bench/`](https://github.com/openIE-dev/jouledb/tree/main/bench).

## Core Subsystems

1. **[Claude Apps, MCP Apps (`SEP-1865`) & `.mcpb` Bundles](./claude-apps.md):** Built-in interactive **JouleDB Studio** (`ui://jouledb/studio.html`, `text/html;profile=mcp-app`), `jouledb mcp --data <dir>` (`stdio`), `POST /mcp` (`59` tools), Claude Desktop `.mcpb` bundles, and Antigravity plugin.
2. **[Storage, Pre-Allocated `JWL1`/`WalManager` Extents, 64-Shard Binary `JMVR`/`JWB1`/`JWU1` MVCC SSI & PITR](./pitr-and-abi.md):** B-Tree storage, pre-allocated Write-Ahead Logging (`WAL`), Serializable Snapshot Isolation (`SSI`), 64-shard `MvccStore` + `MvccTableStorage` (`table_id_shards`), `104.7k TPS` `FinancialLedger`, `0.605 ms` lazy Copy-on-Write (`CoW`) SQL branching (`sql_branch_sandbox.rs`, `joule-db-branch`), binary `TLV` + `CRC-32` envelope framing, and WAL `LSN`/timestamp recovery (`v1_stability_and_pitr.rs`).
3. **[SQL, `pgvector` HNSW, Out-of-Core `.jcol` Columnar Engine, `TPC-H` Joins & Multi-Host WAN TCP Raft](./sql-and-consensus.md):** SQL execution over HTTP and PostgreSQL v3 wire (`pgwire` with `psycopg3` `12/12`, `SQLAlchemy 2` `4/4`, `node-pg` `5/5`, `JDBC` `7/7`, `VECTOR(dim)` + `<->`/`<=>`/`<#>` + `USING hnsw`), owned-batch streaming Parquet `COPY` spilling `262,144`-row `.jcol` disk segments in `JCOL_ID_TAG` namespace, vectorized `execute_segmented` (`43 / 43` Official ClickBench on all `99,997,497` rows) + `columnar_join` (`22 / 22` Official `TPC-H` at `SF=0.1`, `SF=1.0`, & `SF=10.0`), `ALP`/`FSST` codecs, and networked TCP Raft (`propose_and_commit`, Raft §6.4 `read_linearizable` `ReadIndex`, TLA+ specs, and multi-host WAN Clojure `elle 0.2.8` verification).
4. **[Amorphous Hyperdimensional Store](./amorphic.md):** Extracts typed semantic atoms (`JSON`, `CSV`, `XML`, `k=v`, prose, triples) into `10,240`-bit Vector Symbolic Architecture (`VSA`) bitvectors with SI unit normalization and bounded-memory streaming.
5. **[Experimental `.jsyn` Low-Rank Bitplanes](./jsyn.md):** Compresses 2D projection tensors into packed binary sign bitplanes (`LittleBit-2 + SVF`). Preserves `0.9441` cosine similarity on compact sentence encoders (`all-MiniLM-L6-v2-LittleBit` at `0.44 BPW`), while ultra-low `0.02–0.17 BPW` settings degrade autoregressive LLMs (`cos = 0.27–0.45`) and are **not** drop-in LLM replacements.
6. **[Wire Adapters & Unaudited Security Controls](./trust.md):** PostgreSQL `pgwire` (tested against `psql`, `psycopg3`, `node-pg`, `JDBC`, `SQLAlchemy`), REST compatibility adapters, and technical security primitives — **explicitly unaudited by any external SOC 2, HIPAA, PCI-DSS, CMVP, or FedRAMP assessor**.
