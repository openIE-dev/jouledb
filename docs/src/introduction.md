bypasses)**, **beats `PostgreSQL 16.16` across all `4 / 4` durable NVMe Core Banking `LEDGER` regimes (`3,424.5 TPS` [`9.21×`] at `c=1`, `1,412.7 TPS` [`1.82×`] at `c=4`, `3,919.0 TPS` [`1.37×`] at (`<->`/`<=>`/`<#>`)**, executes the **entire official `99,997,497`-row (`14.78 GB`) ClickBench `hits.parquet` suite on NVMe in `139.2 MB` post-load RSS (`9.45 GB` peak `VmHWM`, `8 / 43` wins over ## Core Subsystems

1. **[Claude Apps, MCP Apps (`SEP-1865`) & `.mcpb` Bundles](./claude-apps.md):** Built-in interactive **JouleDB Studio** (`ui://jouledb/studio.html`, `text/html;profile=mcp-app`), `jouledb mcp --data <dir>` (`stdio`), `POST /mcp` (`59` tools), Claude Desktop `.mcpb` bundles, and Antigravity plugin.
2. **[Storage, Decoupled `WalManager::log_atomic_tx_fast`, Adaptive `JWL1` Group Commit & 64-Shard `SSI`](./pitr-and-abi.md):** B-Tree storage, `32 MiB` pre-allocated Write-Ahead Logging (`WAL`), Serializable Snapshot Isolation (`SSI`), 64-shard `MvccStore` + `MvccTableStorage`, adaptive group-committed `FinancialLedger` (`4 / 4` regime sweep vs `PostgreSQL 16.16`), `0.553 ms` lazy Copy-on-Write (`CoW`) SQL branching (`sql_branch_sandbox.rs`), binary `TLV` + `CRC-32` envelope framing, and WAL `LSN`/timestamp recovery (`v1_stability_and_pitr.rs`).
3. **[SQL, `pgvector` HNSW, Out-of-Core `.jcol` Columnar Engine, `PK-FD` `TPC-H` Joins & Multi-Host WAN TCP Raft](./sql-and-consensus.md):** SQL execution over HTTP and PostgreSQL v3 wire (`pgwire` with `block_in_place`, `psycopg3` `12/12`, `SQLAlchemy 2` `4/4`, `node-pg` `5/5`, `JDBC` `7/7`, `VECTOR(dim)` + `<->`/`<=>`/`<#>` + `USING hnsw`), streaming Parquet `COPY` spilling `262,144`-row `.jcol` disk segments (`139.2 MB` post-load RSS on `100M` ClickBench), vectorized `execute_segmented` (`43 / 43` Official ClickBench) + `columnar_join` (`22 / 22` Official `TPC-H` at `SF=0.1`, `SF=1.0` [`0.93 s`], & `SF=10.0` [`7.44 s`]), `ALP`/`FSST` codecs, and networked TCP Raft (`propose_and_commit`, Raft §6.4 `read_linearizable` `ReadIndex`, TLA+ specs, and multi-host WAN Clojure `elle 0.2.8` verification).
4. **[Amorphous Hyperdimensional Store](./amorphic.md):** Extracts typed semantic atoms (`JSON`, `CSV`, `XML`, `k=v`, prose, triples) into `10,240`-bit Vector Symbolic Architecture (`VSA`) bitvectors with SI unit normalization and bounded-memory streaming.
5. **[Experimental `.jsyn` Low-Rank Bitplanes](./jsyn.md):** Compresses 2D projection tensors into packed binary sign bitplanes (`LittleBit-2 + SVF`). Preserves `0.9441` cosine similarity on compact sentence encoders (`all-MiniLM-L6-v2-LittleBit` at `0.44 BPW`), while ultra-low `0.02–0.17 BPW` settings degrade autoregressive LLMs (`cos = 0.27–0.45`) and are **not** drop-in LLM replacements.
6. **[Wire Adapters & Unaudited Security Controls](./trust.md):** PostgreSQL `pgwire` (tested against `psql`, `psycopg3`, `node-pg`, `JDBC`, `SQLAlchemy`), REST compatibility adapters, and technical security primitives — **explicitly unaudited by any external SOC 2, HIPAA, PCI-DSS, CMVP, or FedRAMP assessor**.
