## Abstract

Modern data stacks fracture across three incompatible silos: **Agent-native sandboxes** (which fork state cheaply but lack financial invariants and relational analytics), **Core Banking vaults** (which enforce `128-bit` double-entry balances without SQL, joins, or analytics), and **Human developer/analyst RDBMSs** (which lack O(1) SQL branching, agent blast-radius caps, and embedded double-entry ledgers). **JouleDB (`v0.14.0`)** explores unifying all three inside a single open-source Rust workspace where exact `128-bit` `NUMERIC(38, s)` & binary `JWL1` group-committed double-entry accounting, session-isolated Copy-on-Write SQL branches & durable `WORKFLOW` checkpoints, out-of-core `.jcol` vectorized columnar scans & Snowflake multi-table hash joins, PostgreSQL `pgwire` SQL, multi-host WAN TCP Raft `ReadIndex` consensus, `SEP-1865` MCP Apps interactive UI, `10,240`-bit `Amorphic` VSA holograms, and `.jsyn` sentence-embedding bitplanes share one storage and energy-accounting substrate (`reported_j` vs `est_j`).
