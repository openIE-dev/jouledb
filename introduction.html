JouleDB v1.0.0

Introduction

JouleDB (v0.12.0 Pre-1.0 Research Preview) is an open-source (Apache-2.0 OR MIT) multi-model database, hyperdimensional semantic store, MCP Apps (SEP-1865) host, and experimental low-bitwidth tensor runtime written in Rust.

Audit Remediation (v0.6.0) & Engine Upgrades (v0.7.0–v0.12.0, 2026-11-26): Following an external source-level audit in November 2026, v1.0.0 was retracted/yanked, synthetic frontier AI exam routes (frontier_exam_routes.rs) and the unrelated 1.11M-line joule-web crate were deleted, 81 unverified low-BPW .jsyn causal LLM checkpoints were removed from Hugging Face, and Linux release binaries were rebuilt against GLIBC <= 2.35 (verified on Ubuntu 24.04 LTS). v0.12.0 enforces deny(clippy::unwrap_used) across all 41 / 41 workspace crates (100%, 0 bypasses), narrows the entire official 99,997,497-row (14.78 GB) ClickBench hits.parquet suite to 2.11× geomean latency (2.03× reported_j) vs DuckDB 2.0.1 (43 / 43 queries, 5.90 GB post-load RSS, 7 / 43 wins), completes 22 / 22 (100%) Official TPC-H queries exact across SF = 0.1 (1.99× geomean, 5 wins), SF = 1.0 (8.66M rows in 1.78 s, 4.33× geomean, 201.4 MB post-load RSS), AND SF = 10.0 (86.6M rows / 60M lineitem out-of-core in 755.3 MB post-load RSS [46.1× down from 34.81 GB], 15.46 s total [2.20× faster], 8.49× geomean), scales physical-NVMe 100-warehouse pgwire OLTP with binary JWU1 delta UPDATEs to 5,159.7 TPS (c=16, beating PostgreSQL 16.16 1.63× at c=1 Simple, invariant_verified = true), ships built-in Claude/MCP Apps (SEP-1865) Studio UI (ui://jouledb/studio.html, 50 tools, .mcpb bundles), and verifies 5-node Multi-Host Cross-Machine WAN/Tailscale TCP Raft (ReadIndex + SIGKILL + raft.wal) with official Clojure elle 0.2.8 ({:valid? true}). All benchmark scripts, raw JSON/EDN outputs, wins, and losses are published in bench/.

    • #![cfg_attr(not(test), deny(clippy::unwrap_used))] is enforced across all 41 / 41 workspace crates (100%, 0 #[allow(clippy::unwrap_used)] bypasses) with a blocking cargo clippy --workspace --lib --bins --locked CI gate.
  • Energy Evidence Discipline (measured_j ⊥ reported_j ⊥ est_j ⊥ unmetered): Matching research.openie.dev, JouleDB separates inline hardware shunt meters (measured_j — never emitted by software alone), OS/PMU counters (reported_j via Linux RAPL / macOS powermetrics or IOReport on multi-millisecond/second workloads), analytical byte/instruction cost models (est_j for sub-millisecond in-process paths), and unmetered (null joules).

Core Subsystems

  1. Claude Apps, MCP Apps (SEP-1865) & .mcpb Bundles: Built-in interactive JouleDB Studio (ui://jouledb/studio.html, text/html;profile=mcp-app), jouledb mcp --data <dir> (stdio), POST /mcp (50 tools), Claude Desktop .mcpb bundles, and Antigravity plugin.
  2. Storage, 64-Shard Binary JMVR/JWB1/JWU1 MVCC SSI & PITR: B-Tree storage, Write-Ahead Logging (WAL), Serializable Snapshot Isolation (SSI), 64-shard MvccStore + MvccTableStorage (table_id_shards) with binary JMVR\x01, JWB1, & JWU1 delta serialization, O(1) PK/UNIQUE index checks and group-committed WAL batches, Copy-on-Write (CoW) branching (joule-db-branch), binary TLV + CRC-32 envelope framing, and WAL LSN/timestamp recovery (v1_stability_and_pitr.rs).
  3. SQL, Out-of-Core .jcol Columnar Engine, TPC-H Joins & Multi-Host WAN TCP Raft: SQL execution over HTTP and PostgreSQL v3 wire (pgwire with SchemaMetaCache, GSSENCRequest negotiation, cached Describe, direct portal.params, and thread-local AST cache), owned-batch streaming Parquet COPY spilling 262,144-row .jcol disk segments in JCOL_ID_TAG namespace, vectorized execute_segmented (43 / 43 Official ClickBench on all 99,997,497 rows) + columnar_join (22 / 22 Official TPC-H at SF=0.1, SF=1.0, & SF=10.0), window functions, CUBE, recursive CTEs, ALP/FSST codecs, and networked TCP Raft (raft.rs, raft_transport.rs, examples/raft_wan_node.rs) with propose_and_commit, Raft §6.4 read_linearizable (ReadIndex), TLA+ specifications, and multi-host WAN Clojure elle (0.2.8) verification.
  4. Amorphous Hyperdimensional Store: Extracts typed semantic atoms (JSON, CSV, XML, k=v, prose, triples) into 10,240-bit Vector Symbolic Architecture (VSA) bitvectors with SI unit normalization and bounded-memory streaming.
  5. Experimental .jsyn Low-Rank Bitplanes: Compresses 2D projection tensors into packed binary sign bitplanes (LittleBit-2 + SVF). Preserves 0.9441 cosine similarity on compact sentence encoders (all-MiniLM-L6-v2-LittleBit at 0.44 BPW), while ultra-low 0.02–0.17 BPW settings degrade autoregressive LLMs (cos = 0.27–0.45) and are not drop-in LLM replacements.
  6. Wire Adapters & Unaudited Security Controls: PostgreSQL pgwire (tested against psql, psycopg3, node-pg, JDBC, SQLAlchemy), REST compatibility adapters, and technical security primitives — explicitly unaudited by any external SOC 2, HIPAA, PCI-DSS, CMVP, or FedRAMP assessor.
